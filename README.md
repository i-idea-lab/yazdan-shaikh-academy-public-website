---

## Structure & Placeholder Markers

All unverified marketing claims, invented metrics, fictional testimonials, and unconfirmed syllabi have been removed. Sections awaiting verified copy from Yazdan Academy are explicitly labeled with `[Placeholder text]` / `Awaiting Content` markers on the page.

- `index.html` — One-pager layout with official Yazdan Academy branding, verified links, and explicit placeholder slots where content is still pending.
- `assets/logo.png` & `assets/favicon.png` — Official logo mark and favicon retrieved from `https://yazdanshaikhacademy.com/`.
- `styles.css` — Custom styles, scrollbar styling, and transitions.
- `script.js` — Mobile menu, track filtering, FAQ accordion, and placeholder inquiry modal.

---

## Preview Locally

Open `index.html` directly in a browser, or run a local static server:

```powershell
python -m http.server 3000
```

Then visit `http://localhost:3000`.
