## 🚀 Features & Architecture

1. **Brand Identity & Aesthetic:**
   - Designed with an emerald, slate, and gold palette representing digital excellence and authentic Islamic values (*Deen & Dunya*).
   - Glassmorphism panels, soft ambient glows, and clean typography (`Plus Jakarta Sans` & `Cinzel`).

2. **Core Website Sections:**
   - **Hero Section:** High-converting headline, social proof badge, and dual CTA ("Start Learning Today" and "Watch Free Lessons").
   - **Stats Bar:** Dynamic animated counters highlighting community size, students mentored, and project completion rates.
   - **About Yazdan Shaikh:** Personal story, philosophy, and the 3 core pillars (Real-World Skills, Spiritual Elevation, Live Mentorship).
   - **Flagship Courses & Filtering:** Interactive tab switcher for **Digital Skills** and **Arabic & Deen**, covering Full-Stack Video Editing, Quranic Arabic & Tajweed Mastery, and Content Creation / Ethical Branding.
   - **Why Choose Yazdan Academy:** 6-card feature grid with micro-interactions.
   - **4-Stage Mastery Roadmap:** Clear step-by-step breakdown from beginner tools to portfolio creation and landing international clients.
   - **Student Testimonials:** Verified reviews from video editors, students, and homemakers.
   - **Community & Social Showcase:** Prominent subscribe and follow cards for YouTube and Instagram.
   - **Interactive FAQ Accordion:** Clean animated accordion addressing PC specifications, recordings, and beginner accessibility.
   - **Enrollment Lead Capture Modal:** Interactive dialog with course pre-selection and instant toast confirmation.
   - **Sticky Navigation & Mobile Drawer:** Full responsive navigation for mobile, tablet, and desktop.

## 🛠️ How to Preview Locally

Simply double-click `index.html` to open it in any web browser, or run a local HTTP server:

```powershell
# Using Python
python -m http.server 3000

# Using Node.js (npx)
npx serve .
```

Then visit `http://localhost:3000`.
